1 动词三大家族分类与火眼金睛判定法

日语句子中的动词根据变形规则严格分为三大类（学术上称为“五段/一段/变格”）：

类别名称 特征与词尾 典型例词（辞书形） 变形难度与特点
一类动词
(五段动词)		 词尾不是「る」，或者词尾是「る」但倒数第二个假名在 a/u/o 段 行く、飲む、話す、買う、終わる 词尾假名在 あ/い/う/え/お 五段跳跃，规则最丰富
二类动词
(一段动词)		 词尾必须是「る」，且倒数第二个假名在 i段（上一段） 或 e段（下一段） 食べる (be-ru)、見る (mi-ru)、起きる (ki-ru)、諦める (me-ru) 最乖巧！变形直接扔掉「る」接零件即可
三类动词
(サ变/カ变动词)		 仅有两个词：
1. する (做)
2. 来る (くる，来)		 勉強する、愛する、連れてくる 不规则，直接当成固定单词记住变形
🔥 动词判定 3 步极简决策树
  1. 先看是不是 する 或 来る？ → 三类动词。
  2. 词尾不是「る」吗？（如 買う、行く、飲む、話す） → 100% 一类动词！
  3. 词尾是「る」：读倒数第二个假名的元音：
    • 元音为 a/u/o（如 終わる、乗る） → 一类动词
    • 元音为 i/e（如 食べる、見る） → 95% 为二类动词
⚠️ 必背陷阱！外表像二类，实为一类的常见词
下列动词长着 i/e+る 的二类脸，但全是一类（五段）动词：
• 帰る（かえる·回家） → 帰らない / 帰ります
• 入る（はいる·进入） → 入らない / 入ります
• 走る（はしる·奔跑） → 走らない / 走ります
• 知る（しる·知道） → 知らない / 知ります
• 切る（きる·切/剪） → 切らない（注：着る 穿衣是二类）
• 要る（いる·需要）、喋る（しゃべる·聊天）、減る（へる·减少）

第二章 · 动词基础六大形态活用（五十音图规律）

一类动词在 あ/い/う/え/お 行跳跃，二类动词直接丢「る」接后缀
2 动词活用总览大对照表
🎯【动词六大形态到底是干嘛的？—— 一分钟大白话破译】
初学最容易被“未然、连用、终止”这些晦涩称呼搞懵。其实记住它们的人话真正用途即可：
• 未然形：事情还没发生呢 ➔ 变【否定·不干】(ない)、【被动·挨打】(れる)、【使役·让别人干】(せる)
• 连用形：连接后面的零件 ➔ 变【礼貌·敬体】(ます)、【想做·愿望】(たい)、或连句中顿
• 终止形/连体形：原原本本的原形 ➔ 句尾【直接结句】或直接挂在名词前【充当定语】(如: 食べる人)
• 假定形：假设条件 ➔ 接「ば」表示【如果……就……】(如: やればできる 只要去干就能成)
• 命令形：长官命令手下 ➔ 强硬命令【快去！】(如: 逃げろ 快逃！ 行け 冲！)
• 意志形：表达决心与邀请 ➔ 【我要…… / 咱们一起……吧】(如: 归ろう 咱们回吧！ 行こうぜ 出发！)

把动词原形与你在动漫中听到的各种语气对号入座：

1. 未然形 【干嘛的：表否定 / 被动】
+ ない / れる
💡 用途解说：动作还“未发生”，用来变“不……”(ない)或“被动/可能”(れる/られる)。
📐 变换法则：一类动词词尾变 あ段 (kak-u ➔ kak-a) ；二类动词直接丢「る」
一类动词 (書く)
• 書か-ない (不写)
• 書か-れる (被写)
二类动词 (食べる)
• 食べ-ない (不吃)
• 食べ-られる (能/被吃)
🎬 动漫名台词：負けない！ 绝不认输！ / 諦めないで 请别放弃
2. 连用形 【干嘛的：表礼貌敬体 / 想要】
+ ます / たい
💡 用途解说：“连接用言”，用来变礼貌敬体(ます)、愿望想做(たい)、动名词或连句中顿。
📐 变换法则：一类动词词尾变 い段 (kak-u ➔ kak-i) ；二类动词直接丢「る」
一类动词 (書く)
• 書き-ます (写-礼貌)
• 書き-たい (想写)
• 書き物 (书写物)
二类动词 (食べる)
• 食べ-ます (吃-礼貌)
• 食べ-たい (想吃)
• 食べ物 (食物)
🎬 动漫名台词：行きます！ 我出发了！ / 会いたい 好想见你！
3. 终止形 / 连体形 【干嘛的：原形结句 / 修饰名词】
辞书原形 (う段)
💡 用途解说：字典原貌。句尾直接打句号结句(终止形)，或直接放在名词前面充当定语(连体形)。
📐 变换法则：保持词尾 う段（辞书形原样不变）
一类动词 (書く)
• 書く (写-结句)
• 書く人 (写字的人-定语)
二类动词 (食べる)
• 食べる (吃-结句)
• 食べる人 (吃东西的人-定语)
🎬 动漫名台词：俺が守る！ 由我来守护！ / 行くぞ！ 上吧！
4. 假定形 【干嘛的：表如果……假设条件】
+ ば (如果)
💡 用途解说：假设条件，后接「ば」表示“如果……就……”、“只要……就能……”。
📐 变换法则：一类动词词尾变 え段 (kak-u ➔ kak-e) ；二类动词变 れ (tabe-re)
一类动词 (書く)
• 書け-ば (如果写的话)
二类动词 (食べる)
• 食べれ-ば (如果吃的话)
🎬 动漫名台词：逃げれば助かる 如果逃就能活！ / やればできる 只要去干就能成！
5. 命令形 【干嘛的：强硬命令 / 热血喊话】
直接结句！
💡 用途解说：长官命令手下、危急时刻或动漫热血战斗中，强硬命令对方立即去做。
📐 变换法则：一类动词词尾变 え段 (kak-e) ；二类动词词尾变 ろ / よ (tabe-ro / mi-ro)
一类动词 (書く)
• 書け！ (快写！)
• 行け！ (冲！)
二类动词 (食べる)
• 食べろ！ (快吃！)
• 見ろ！ (看！)
🎬 动漫名台词：逃げろ！ 快逃！ / 死ね！ 去死吧！ / 行け！ 冲啊！
6. 意志形 【干嘛的：自身决心 / 提议邀请】
お段+う / よう
💡 用途解说：表达自己的主观意愿决心（“我要……”），或向伙伴发出邀请提议（“咱们一起……吧！”）。
📐 变换法则：一类动词变 お段+う (kak-o + u ➔ かこう) ；二类动词去る加 よう (tabe-you)
一类动词 (書く)
• 書こう (写吧！/我要写)
• 行こう (咱们走吧)
二类动词 (食べる)
• 食べよう (吃吧！)
• 見よう (看吧！)
🎬 动漫名台词：帰ろう 咱们回去吧 / 行こうぜ！ 咱们出发吧！

第三章 · 攻克最大难关：一类动词「て形 / た形」音便法则

把动词变成连接形（请求）与过去式（发生）的终极发音顺畅法则
3 音便口诀与变换全览表

为什么需要“音便”？因为一类动词如果直接接「て/た」会极其拗口（如 kak-ite 读起来很费劲）。为了发音圆润省力，日本人在历史上自然演变出了音便。

🎵 终身难忘的「て形音便押韵口诀」（牢记这四句！）
① う・つ・る 变成 促音 って（買う → 買って、待つ → 待って、帰る → 帰って）
② ぬ・ぶ・む 变成 拨音 んで（死ぬ → 死んで、遊ぶ → 遊んで、飲む → 飲んで）
③ く 变 いて，ぐ 变 いだ（書く → 書いて、泳ぐ → 泳いで）【★特例：行く 变成 行って！】
④ す 结尾 最省心，直接变成 して（話す → 話して、探す → 探して）
↔️ 宽表可左右滑动
音便种类 动词词尾 て形（连接/请求） た形（过去式/完成）

(鼻音ん+浊音で)		 ぬ、ぶ、む 死んで、遊んで、飲んで 死んだ (死了)、遊んだ、飲んだ

(变元音い)		 く、ぐ 書いて、聞いて、泳いで 書いた、聞いた (听到了)、泳いだ

常规变して す 話して、出して、隠して 話した (说了)、出した、隠した
二类动词 直接去「る」 食べて、見て、信じて 食べた、見た、信じた (我相信了)
三类动词 する / くる して (愛して) / きて (連れてきて) した (成功した) / きた (奴が来た！)
💡 「た形」与「て形」是孪生兄弟：
只要掌握了「て形」，把「て」换成「た」，把「で」换成「だ」，就立刻拿下了动词过去式「た形」！ 例：飲んで → 飲んだ（喝了）；行って → 行った（去了）；食べて → 食べた（吃了）。

🔷 て形衍生高频核心句型
  • 〜ている：正在进行 / 状态持续（例：戦っている 战斗中；知っている 知道）
  • 〜てください：请做某事（例：助けてください 请救救我）
  • 〜てみる：尝试做做看（例：やってみる 试着干干看）
  • 〜ておく：事先准备好（例：買っておく 提前买好）
  • 〜てしまう：彻底做完 / 遗憾糟糕（例：死んでしまう 要死掉了）
  • 〜てもいい：可以……许可（例：入ってもいい？ 可以进去吗？）
  • 〜てはいけない：不可以/禁止（例：諦めてはいけない 不能放弃）
🔶 ない形衍生高频核心句型
  • 〜ないで（ください）：请不要做……（例：行かないで 别走）
  • 〜なければならない：必须做……（例：守らなければならない 必须守护）
  • 〜なくてもいい：不……也可以（例：言わなくてもいい 不说也行）
  • 〜ないほうがいい：最好别做……（例：触らないほうがいい 最好别碰）

1 终生宿敌对决①：【は】 vs 【が】（主题 vs 主格）

↔️ 宽表可左右滑动
对比维度 【は】（提示助词 · 提主题） 【が】（格助词 · 指定主格）

7 ⚠️ 动漫爱好者现实交际“防踩雷”三大铁律
🚫 避坑警告：切勿把动漫热血口语直接搬到现实生活！
  1. 千万别对真人叫「お前（おまえ）」或「あんた」！
    在动漫里男主对同伴叫“お前”显得很帅，但在日本现实生活中，“お前”是极其傲慢、粗鲁甚至具有挑衅攻击性的词！现实中称呼任何人，请一律称呼对方姓氏 + さん（如「田中さん」、「佐藤さん」），或者直接省略主语！
  2. 初次见面或面对长辈，必须收起“〜ぜ、〜だ、すげえ”！
    动漫里的主角对谁都说普通体（タメ口）。但现实中面对店员、路人、长辈、老师或刚认识的朋友，不加「です/ます」会被判定为极度没有家教。请使用标准的敬体：「すごいです」、「ありがとうございます」。
  3. 警惕中二病古风词汇！
    动漫里的「貴様（きさま）」、「我が名は…」、「我（われ）」属于特定历史剧或奇幻世界观产物，在现代日本社会讲出来会引发极其尴尬的空气凝固。
