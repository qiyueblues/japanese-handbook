1 动词三大家族分类与火眼金睛判定法

日语句子中的动词根据变形规则严格分为三大类（学术上称为“五段/一段/变格”）：

类别名称 特征与词尾 典型例词（辞书形） 变形难度与特点
一类动词
(五段动词)		 词尾不是「る」，或者词尾是「る」但倒数第二个假名在 a/u/o 段 行く、飲む、話す、買う、終わる 词尾假名在 あ/い/う/え/お 五段跳跃，规则最丰富
二类动词
(一段动词)		 词尾必须是「る」，且倒数第二个假名在 i段（上一段） 或 e段（下一段） 食べる (be-ru)、見る (mi-ru)、起きる (ki-ru)、諦める (me-ru) 最乖巧！变形直接扔掉「る」接零件即可
三类动词
(サ变/カ变动词)		 仅有两个词：
1. する (做)
2. 来る (くる，来)		 勉強する、愛する、連れてくる 不规则，直接当成固定单词记住变形
🔥 动词判定 3 步极简决策树
  1. 先看是不是 する 或 来る？ → 三类动词。
  2. 词尾不是「る」吗？（如 買う、行く、飲む、話す） → 100% 一类动词！
  3. 词尾是「る」：读倒数第二个假名的元音：
    • 元音为 a/u/o（如 終わる、乗る） → 一类动词
    • 元音为 i/e（如 食べる、見る） → 95% 为二类动词
⚠️ 必背陷阱！外表像二类，实为一类的常见词
下列动词长着 i/e+る 的二类脸，但全是一类（五段）动词：
• 帰る（かえる·回家） → 帰らない / 帰ります
• 入る（はいる·进入） → 入らない / 入ります
• 走る（はしる·奔跑） → 走らない / 走ります
• 知る（しる·知道） → 知らない / 知ります
• 切る（きる·切/剪） → 切らない（注：着る 穿衣是二类）
• 要る（いる·需要）、喋る（しゃべる·聊天）、減る（へる·减少）

第三章 · 攻克最大难关：一类动词「て形 / た形」音便法则

把动词变成连接形（请求）与过去式（发生）的终极发音顺畅法则
3 音便口诀与变换全览表

为什么需要“音便”？因为一类动词如果直接接「て/た」会极其拗口（如 kak-ite 读起来很费劲）。为了发音圆润省力，日本人在历史上自然演变出了音便。

🎵 终身难忘的「て形音便押韵口诀」（牢记这四句！）
① う・つ・る 变成 促音 って（買う → 買って、待つ → 待って、帰る → 帰って）
② ぬ・ぶ・む 变成 拨音 んで（死ぬ → 死んで、遊ぶ → 遊んで、飲む → 飲んで）
③ く 变 いて，ぐ 变 いだ（書く → 書いて、泳ぐ → 泳いで）【★特例：行く 变成 行って！】
④ す 结尾 最省心，直接变成 して（話す → 話して、探す → 探して）
音便种类 动词词尾 て形（连接/请求） た形（过去式/完成）
促音便
(促音停顿っ)		 う、つ、る 買って、待って、勝って、終わって 買った、待った、勝った (赢了！)、終わった
拨音便
(鼻音ん+浊音で)		 ぬ、ぶ、む 死んで、遊んで、飲んで 死んだ (死了)、遊んだ、飲んだ
い音便
(变元音い)		 く、ぐ 書いて、聞いて、泳いで 書いた、聞いた (听到了)、泳いだ
★ 唯一特例 行く（いく） 行って（绝不是 いいて！） 行った（去了！）
常规变して す 話して、出して、隠して 話した (说了)、出した、隠した
二类动词 直接去「る」 食べて、見て、信じて 食べた、見た、信じた (我相信了)
三类动词 する / くる して (愛して) / きて (連れてきて) した (成功した) / きた (奴が来た！)
💡 「た形」与「て形」是孪生兄弟：
只要掌握了「て形」，把「て」换成「た」，把「で」换成「だ」，就立刻拿下了动词过去式「た形」！ 例：飲んで → 飲んだ（喝了）；行って → 行った（去了）；食べて → 食べた（吃了）。

第四章 & 第五章 · 派生句型与动漫口语变体大字典

把动词形态组装成句子，并逆向破译动漫常见口语缩音与语气词
4 动词进阶句型：以「て形」与「ない形」为核心的派生宇宙
🔷 て形衍生高频核心句型
  • 〜ている：正在进行 / 状态持续（例：戦っている 战斗中；知っている 知道）
  • 〜てください：请做某事（例：助けてください 请救救我）
  • 〜てみる：尝试做做看（例：やってみる 试着干干看）
  • 〜ておく：事先准备好（例：買っておく 提前买好）
  • 〜てしまう：彻底做完 / 遗憾糟糕（例：死んでしまう 要死掉了）
  • 〜てもいい：可以……许可（例：入ってもいい？ 可以进去吗？）
  • 〜てはいけない：不可以/禁止（例：諦めてはいけない 不能放弃）
🔶 ない形衍生高频核心句型
  • 〜ないで（ください）：请不要做……（例：行かないで 别走）
  • 〜なければならない：必须做……（例：守らなければならない 必须守护）
  • 〜なくてもいい：不……也可以（例：言わなくてもいい 不说也行）
  • 〜ないほうがいい：最好别做……（例：触らないほうがいい 最好别碰）
  • 辞书形 + な！：【绝对禁止】绝对别做！（例：逃げるな！ 不许逃！）
